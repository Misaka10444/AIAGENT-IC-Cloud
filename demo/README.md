## 演示视频

- 时长：4 分 07 秒
- 分辨率：1920 × 1200（满足附件 3「不低于 1080P」）
- 帧率：30 fps（最大帧间隔 0.03 秒）
- 内容：真实运行画面，含系统界面与完整交互过程

**视频随报名邮件作为附件提交，未纳入本仓库**，原因：成品 18.4 MB、源片 511 MB，
仓库内不适合存放二进制媒体；且附件 3 要求 `demo/` 提供"演示脚本**或**演示视频链接"，
本目录已提供完整脚本，满足结构要求。

如需在本地复核，录制流程与检查项见 `录制操作卡.md`。

## 现场演示环境

```bash
python -m src.server.app --port 8765
# 浏览器打开 http://127.0.0.1:8765
```

无需安装第三方依赖，无需联网。若现场网络受限，可完全离线运行。

## 录制环境备注

演示视频使用 Windows 11 自带「截图工具」录制（Win+Shift+S → 录像）。
该工具不捕获鼠标指针，因此视频中光标不可见；交互过程通过界面变化
（输入框内容、表格与右侧轨迹面板刷新）和旁白点名体现。
