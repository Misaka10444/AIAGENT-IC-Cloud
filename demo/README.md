# 演示材料

本目录存放模块 B（Agent 原型演示）相关的演示材料。

| 文件 | 说明 |
| --- | --- |
| `demo_script.md` | 演示视频脚本与分镜，含逐镜台词、录制检查清单 |

## 演示视频

- 时长：≤ 5 分钟
- 分辨率：1920×1080
- 内容：真实运行画面，含系统界面与完整交互过程
- 链接：**【提交前填写网盘或视频平台链接】**

视频中出现的全部数据均为仓库自带的脱敏样例（S001—S003），不含真实个人信息。

## 现场演示环境

```bash
python -m src.server.app --port 8765
# 浏览器打开 http://127.0.0.1:8765
```

无需安装第三方依赖，无需联网。若现场网络受限，可完全离线运行。
