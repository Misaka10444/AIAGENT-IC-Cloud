# 《Agent 原型演示》视频脚本与分镜

> 模块 B · Agent 原型演示（30 分）
> 时长上限 5 分钟　·　分辨率不低于 1080P　·　必须为真实运行画面，不得剪辑拼接伪造效果

## 0 录制前置条件

| 项目 | 要求 | 本机核对方式 |
| --- | --- | --- |
| 分辨率 | 1920×1080（16:9），系统缩放到 100% 避免模糊 | 显示设置 → 缩放 100% |
| 帧率 | 30fps 即可 | OBS / Xbox Game Bar 默认 |
| 声音 | 旁白清晰，无键盘回声 | 建议耳麦，录制前试录 10 秒回听 |
| 光标 | 必须可见，观众要能跟上操作 | 系统设置 → 鼠标 → 显示指针轨迹可开短 |
| 界面 | 浏览器 100% 缩放、隐藏书签栏 | F11 全屏 + 隐藏书签栏 |
| 数据 | 使用仓库自带脱敏样例（S001—S003） | 不得出现真实姓名学号 |

启动命令：

```bash
python -m src.server.app --port 8765
```

浏览器打开 `http://127.0.0.1:8765`，确认左下角显示「知识库：7 篇 / 34 片段」「工具：10 个」。

**录制纪律**：一次录完，不剪辑拼接；若某段失败，从头重录该段并保留完整时间连续性。
视频前 3 秒必须能看到浏览器地址栏与系统时间，作为真实运行的锚点。

## 2 逐镜台词（可直接照读）

**镜头 1（0:00–0:15）**
> 这是云梯，一款面向职业本科学生的学业规划与选课顾问智能体。参赛队 Cloud，来自集成电路学院。

**镜头 2（0:15–0:35）**
> 它不做泛泛的聊天，只做四件确定的事：按培养方案的六个模块核算学分、在五类约束下生成学期选课方案、
> 判定先修与毕业资格、回答制度问题并给出原文出处。

**镜头 3（0:35–1:20）**
> 先看学分。学生最常犯的错是只记住总学分一百四十四，却忽略模块分别有门槛。
> 这里给出的是六个模块各自的达标情况：通识必修缺十，专业核心缺四十一，专业选修缺十五。
> 下面单独列出未通过的课程——这门面向对象程序设计五十二分，不计入达标学分，必须重修。

**镜头 4（1:20–1:30）**
> 右侧三条引用都带文档号和原文行号。评审核对时不需要相信我，直接回到原文。

**镜头 5（1:30–2:20）**
> 核心场景是选课方案。系统要同时满足五类约束：先修关系、上课时间、每学期学分上限、教学班容量，
> 还有学生自己的偏好——这位学生回避周一早八，方案里就没有出现周一第一二节。
> 这是真实的约束求解，不是把课程列表抄一遍。

**镜头 6（2:20–2:40）**
> 更关键的是这一段：被排除的课程都写了原因。操作系统和数据库都在周二第三四节，撞课；
> 机器学习基础容量已满，一百二十个名额选满了；Python 数据分析因为先修课没通过被排除。
> 这些理由就是学生真正需要的信息。

**镜头 7（2:40–3:00）**
> 右侧是智能体内部的执行轨迹：规划、检索、工具、校验、生成。哪一步调了什么工具、耗时多少、有没有重试，
> 全部落在日志里。这也是我们做评测的数据来源。

**镜头 8（3:00–3:30）**
> 多轮对话。先问某门课的选课资格，再用「那门课」来指代。系统把它替换成上一轮提到的课程，
> 替换依据写在轨迹里：代词是「那门课」，解析到《大模型应用开发》，证据是上一轮课程代码。

**镜头 9（3:30–3:55）**
> 毕业资格是逐项一票否决。这位学生五项里四项没通过：总学分差五十、模块不达标、
> 还有一门专业核心课没修、毕业设计与顶岗实习未完成。每项都写明差多少。

**镜头 10（3:55–4:15）**
> 制度问答走的是检索增强：先把问题改写成检索式，再召回片段，低于相关性阈值就不答。
> 补考最高记六十分这条，来自重修规定的原文，不是模型背下来的。

**镜头 11（4:15–4:30）**
> 边界同样重要。知识库没有的问题，它明确说没有找到依据，不编造；
> 让它预测成绩，它直接拒绝——这两条都在代码里强制，不靠提示词自觉。

**镜头 12（4:30–4:50）**
> 这些都是可复现的。五十条功能用例、二十五条检索用例，一条命令跑完。
> 特征重排让 Top-1 文档命中率从百分之八十四提升到八十八。

**镜头 13（4:50–4:55）**
> 每条回答都带 AI 生成标识，结论不替代教务处与学院的正式审核。
